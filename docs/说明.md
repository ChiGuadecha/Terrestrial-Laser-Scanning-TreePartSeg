# 树干 / 树枝 / 树叶 分离成果

> **完成人：梁艺萌**　·　本成果与源代码的著作权归完成人所有，**未经本人允许不得商用**；第三方组件许可见源码包 `NOTICE.txt`。

完整分步解析见 `docs/工作流程.md`，流程图见 `docs/工作流程图.png`（01→30 蛇形流程）。

模型：Point Transformer V3（Pointcept 官方实现，纯 PyTorch 前向）+ Sonata/ScanNet 预训练权重迁移；输入 11 维几何特征（坐标 3 + 朝向法向 3 + 相对高度 1 + 局部线度/面度/球度/kNN 半径 4）。

## 流程

- 训练标签：由提供的 leaf/wood 标注 + 几何伪标注生成三分类（水平切片 → 5cm 栅格连通域 → 圆柱轴追踪，主干自地面沿最粗脊线延伸到顶部）
- 细枝采样 + 加权损失：训练时对 branch 点做抖动过采样（oversample），CE 用 sqrt 逆频率权重 + branch 类权重 ×2，并叠加 Lovász-softmax 直接优化 IoU
- 推理：多体素尺度 TTA（0.02 / 0.015 m）× 左右翻转 × 多模型（task3 三分类 + task2 枝叶二分）概率融合
- 后处理：KNN 投票 → 局部连通域细枝修复（只在候选点上做连通域，要求小而细长、贴附木质部、曲率特征达标）→ 孤岛清理 → 带路径长度与方向连续性约束的梢部生长 → 主干圆柱先验（离轴主干降级为枝）→ 主干缝隙桥接 → 仅保留与地面连通的主干（保证主干是一整根、不断裂）
- 验证集最优模型集：ptv3_task3_v4 + ptv3_task2_v3（融合权重 0.25/0.75）

## 测试集结构统计（20 棵）

- 主干连通块数量：全部 20 棵均为 **1 根**（不存在断裂主干）
- 主干起点高度：最大 0.14 m（即从地面起算）
- 主干到达木质部顶端比例：平均 79.6%，最低 43.0%（低值为早分枝/矮干型树木）
- 平均置信度：0.9547

## 模型与参数选型记录

- 三分类模型对比（验证集 pooled mIoU / 末端细枝召回）：v4=0.9203/0.9670，v7f(细体素)=0.9003/0.9228，v4+v7f=0.9143/0.9486，v5=0.8990/0.9611 → 选用 v4
- TTA 尺度：0.02+0.015=0.9203 优于 0.02+0.015+0.01=0.9151、优于 0.0125+0.01=0.9109
- 后处理消融（验证集 pooled mIoU，用 cache/probs_v4_*.npz 在 CPU 上重放）：原始概率 0.9057 → 旧版后处理 0.7869（有害，已否决）→ 新版细枝链 19~22 0.9079 → +主干轴先验 0.9136 → +桥接与单根约束 0.9203

## 说明

- 测试集无地面真值，因此测试树只报告类别占比、平均置信度与主干贯通统计；精度指标一律来自同模型同流程的验证集。
- 主干严格约束为“与地面连通的一整根圆柱”：不在追踪轴上的主干像素降级为树枝，轴上断缝用最近木质点桥接，因此每个 `02_仅主干.png` 中红色部分都是连续单根。
- 主干顶端高度即“足够粗的骨架”能到达的最高点，再往上属于细枝（局部半径低于阈值）。
